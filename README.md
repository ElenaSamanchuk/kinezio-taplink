# Kinezio · таплинк кодом с невидимым таймером

- Исходник: `src/block.html` (стили, разметка и скрипт в одном фрагменте).
- Сборка: `node scripts/build.mjs` → `index.html` (GitHub Pages) и `docs/КОД-для-Тильды-taplink.html` (вставить целиком в один блок T123 на странице /taplink вместо Zero-блоков).
- Виды: `states.html?sales=before|open|after`. Ручной вид на любой странице: `?sales=open`.
- Время (МСК): запуск с 16.11.2026 10:00 до 07.12.2026 00:00. Меняется числами `OPEN_MS` / `CLOSE_MS` в скрипте.
- Запуск: пробный курс «старт 23 ноября» → новый канал Практикума, вверху «Фундамент движения. Старт 7 декабря», у ФД плашка «старт 7 декабря».
- Вне запуска: пробный курс «старт после регистрации» → прошлый пробник (ТЗ в Figma «#dsgn кинезио», страница «таплинк»).
