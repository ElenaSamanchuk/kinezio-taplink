# Проверка таплинка Kinezio на запуск 16.11.2026 без ИИ

Скрипт `scripts/check-launch.mjs` (Node 18+, без зависимостей в проекте; рендер через Playwright из `~/Projects/bi13-highlevel`, `~/Projects/qa-kit` и др., при несовпадении версии берёт любой Chromium из `~/Library/Caches/ms-playwright`). Только чтение: GET/HEAD-запросы и открытие страницы в headless-браузере.

## Команда

    cd ~/Projects/kinezio-taplink && node scripts/check-launch.mjs

Флаги:

    --url=https://...                    другой адрес (по умолчанию GitHub Pages .../kinezio-taplink/index.html), например будущая /taplink на Тильде
    --at "2026-11-16T10:05:00+03:00"     подмена времени (ожидание и часы в браузере)
    --sales=open|before|after            добавить ?sales= к адресу
    --no-browser                         только код и ссылки, без рендера
    --timeout=40000                      таймаут одного запроса, мс

Код выхода: 0 нет ❌ (⚠️ допустимы), 1 есть ❌, 2 неверные аргументы. Вывод построчно ✅/⚠️/❌ и итог.

- Локальный `docs/КОД-для-Тильды-taplink.html`: `#ktl-root`, `OPEN_MS=1794812400000` (16.11.2026 10:00 МСК), `CLOSE_MS=1796590800000` (07.12.2026 00:00 МСК), `data-when`, `a[data-pass]`, ссылки на канал и бота.
- Страница: отвечает 200, код на месте; ожидаемый вид по времени (до 16.11 10:00 before, до 07.12 00:00 open, дальше after) против фактического `data-sales` в браузере.
- open: видны «Практикум» (выше логотипа), «Бесплатно. Старт 23 ноября», «Научимся находить причины боли», кнопка «Вступить в канал» на `https://t.me/+jEUoHcbCU8xlNWUy`; у «Бесплатного пробного курса» плашка «Старт 23 ноября» и та же ссылка; у ФД плашка «Старт 7 декабря»; скрыты «Перейти в бот» и «Институт движения».

## Ограничения

- Ссылки `t.me` не открываются, сверяются только по href; что канал и бот живые, скрипт не знает.
- `--at` подменяет часы только в браузере и в ожидании; `--sales` форсирует вид через параметр, то есть проверяет оформление вида, а не переключение по настоящему времени. Само переключение в 10:00 МСК проверяйте запуском без флагов после старта (или `--at`).
- Если по `--url` код ещё не вставлен (например, Тильда), выводится ⚠️ «код не найден», рендер не проверяется.
- Сайт kineziofitness.online иногда обрывает соединение (замечено 13.11 на coach-encyclopedia, один из прогонов дал `fetch failed`); повторы смягчают, но при красной ссылке перезапустите и сверьте вручную.
- Без `--no-browser` нужен Playwright с Chromium; без него рендер пропускается с ⚠️.
- Не заменяет визуальную проверку дизайна, телефонов и общий смоук сайта.
